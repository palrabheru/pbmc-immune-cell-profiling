# Figures for the GitHub portfolio

This directory is for **real plots generated by the analysis**, not fabricated examples.

After running `python analysis.py`, copy suitable PNGs from `results/figures/` into this directory, then commit and push:

```powershell
Copy-Item results\figures\*.png figures\
git add figures
git commit -m "Add PBMC3k analysis figures"
git push origin main
```

Check figures and cluster interpretation before claiming that a specific cluster is a particular cell type.
